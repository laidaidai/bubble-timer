# 宣传功能图

这些图片来自微信开发者工具中的真实页面渲染，页面内的目标时长、模块、成绩、打卡天数和待办均为本地演示数据，不是真实用户数据；截图过程没有改动项目代码。

## 图片

| 文件 | 功能 |
| --- | --- |
| `01-首页工作台.png` | 首页训练工作台：目标时长、激励番茄、重要日子、训练模块与开始计时 |
| `02-专注计时.png` | 模块化专注计时：总计时、当前模块、目标与节奏提示 |
| `02b-模块切换.png` | 计时页模块选择面板：已完成 / 当前 / 待完成模块 |
| `03-过关斩将.png` | 试卷库：上次成绩、题量、导入答案、自定义与计时入口 |
| `04-答题作答.png` | 答题页：答题进度、模块切换、选项与 AI 导入入口 |
| `05-批改成绩.png` | 成绩报告：总分、正确率、能力图与模块明细 |
| `06-打卡统计.png` | 打卡统计：今日完成度、连续打卡、月历与能力弱项 |

## 尺寸

- `original/`：开发者工具原始截图，596 × 1294。
- `1080/`：按原始比例放大到 1080 × 2345，适合直接用于社媒或宣传物料。

## 建议配文

- 首页：把一天的学习，拆成看得见的小目标。
- 专注计时：一个模块一个模块推进，时间用在哪里一目了然。
- 过关斩将：真题卷、答题卡、成绩分析，练完就知道下一步补哪里。
- 打卡统计：连续专注的每一天，都算数。
