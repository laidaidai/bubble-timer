# 小鱼计时器

一个为备考刷题设计的原生微信小程序，小程序名「小鱼计时器」，首页叫「小鱼时钟」：模块化限时训练放在首页工作台，常规「番茄钟」独立放进快捷计时；练完还能看到每个模块的用时、达标率和趋势。工具页同时接入了「过关斩将」：手动点选或 AI 识别导入作答、导入参考答案、按每题分值判分，全部本地完成。

默认「蜂蜜奶霜」视觉：暖黄底、深棕描边卡片、硬阴影，配柠檬黄点缀；另有红黄汽水 / 蜜桃雪酪 / 晴空苏打 / 薄荷青瓷 / 曜石鎏金等主题，也可自命名自定义配色。

## 功能

- **模块化计时**：首页只保留正计时 / 倒计时两种需要训练模块的模式，模块列表、目标时间和模板都在这里集中管理。
- **独立番茄钟**：快捷计时里的「番茄钟」标签页按常规 25 分钟专注 / 5 分钟休息运行，每完成 4 个番茄自动进入 15 分钟长休息；不再和训练模块绑定，也不会因为某个模块练够时长就自动切模块。
- **模块化训练**：最多 8 个模块，拖动排序、单独设目标分钟；总时间 / 当前模块时间分开显示，翻页时钟、指针时钟等多种表盘可在计时页轻点背景切换，默认记住上次样式，计时页还带两位毫秒小字，竖屏 / 横屏都能用。
- **快捷计时**：工具页「快捷计时」进入普通秒表 / 计时器 / 番茄钟。秒表、计时器和番茄钟都按 `分:秒.两位毫秒` 显示，毫秒与主时间放在同一个时钟底座里、同色调，以约 60fps 刷新避免读数频闪；秒表支持「计次」并列出每次总时间与分段时间；去掉大表盘和背景框，只保留放大居中的时间。计时器未开始时显示循环滚轮（时 / 分 / 秒，滚到尽头会绕回开头，滚动时轻震）和 10 分钟、20 分钟、30 分钟、1 小时、2 小时、3 小时预设，按历史使用次数自动选中常用时长；开始后隐藏选择器和预设，只显示大时钟与按钮。三种模式都可点击时钟切换翻页 / 数字 / 积木 / 极简 / LED 五种样式；切换秒表 / 计时器 / 番茄钟时各自保留进度，进行中的会话切回后继续；离开页面后保留当前计时和计次，返回时按真实时间继续，暂停状态原样恢复。
  布局固定为「tabs / 弹性时钟区 / 页脚按钮」三段式：按钮始终贴底，时钟只在中间容器内按宽高等比缩放，容器随窗口和桌面档重算，任何皮肤、位数或计次列表都不撑出屏幕。
- **沉浸式时钟**：计时页左上角全屏图标可收起模块栏、进度、按钮等全部内容，只保留放大后的时钟；再点左上角关闭图标恢复。翻页时钟按标准 split-flap 先翻上半页旧数字，再翻下半页新数字。
- **三 Tab 分工**：底部自定义 TabBar 分「首页 / 工具 / 记录」。计时页默认是主工作台，显示目标时间、番茄、模式、模板和训练模块，并在下方展示最多 3 个重要日子；工具页以图标进入快捷计时、训练、待办、重要日子、打卡、过关斩将和设置，并直接显示最近待办与重要日子卡片；「训练」回到首页的训练计时，不再另开一套页面；记录页只展示历史记录。
- **过关斩将**：完整页面已迁入 `pages/grade/`，包含题库首页、答题、结果、历史、自定义卷、答案导入和信件页。批改首页带与主程序一致的底部 dock（进入子页时「工具」保持高亮）；从工具页或悬浮球直接进入真实页面，点试卷直接进入答题，草稿自动续答；试卷卡的 ▶ 进入独立「本卷配时」页，按试卷模块调整每段目标时长、拖动调整计时顺序，可保存为该卷方案并直接起跑；作答支持手动点选 A/B/C/D，或在答题页复制 AI 提示词（AI 按每行 20 题、每 5 题一组返回代码块，异常题先在代码块外提醒；有空白答题卡原图时一起发给 AI 做差分对比），拍照识别答题卡后粘贴结果批量填涂；弹层输入框只显示导入教程与 4 个常用格式示例；底层仍兼容分组和题号写法；导入参考答案后按每卷每题真实分值判分，满分 100；纯本地存储，不联网、不接外部题库、不做跨用户统计。
- **统一入口**：首页始终是训练工作台，不再把工具页内容嵌进首页。工具页与悬浮球菜单都只做真实页面导航：训练计时回首页，快捷计时进 `pages/quick/quick`，待办 / 重要日子 / 打卡 / 过关斩将分别进各自的独立页。不在首页复制第二套视图，避免同一功能出现两套布局、动画和尺寸链。
- **首页模板**：默认 6 个通用学习模块（课程学习 / 知识梳理 / 专项练习 / 错题复盘 / 阅读积累 / 总结回顾，共 120 分钟）、8 套真实考试预设模板（国考行测 / 省考行测 / 国考申论 / 事业单位公基 / 考研政治 / 考研英语 / 事业单位职测 / 省考申论）；国考、省考行测均按现行大纲包含政治理论，共 6 个模块。在设置里勾选预设会直接生成同名首页模板。
- **训练报告**：只显示达标率、实际 / 计划用时、最耗时（有多个模块时才有最短时）和练过的模块明细；可保存图片、分享，或一键「再练一次」。
- **打卡**：竖版打卡海报（canvas 导出，含今日目标完成度、本周累计、连续打卡和完整月历），页面直接展示生成后的图片，长按可保存或转发；有数据时才显示弱项追踪与多模块成绩趋势。
- **重要日子倒计时**：从工具页或悬浮球进入独立页，显示完整的添加按钮、列表和日历选择；支持添加、编辑、长按删除，可选「每年重复」，自动计算下一次倒计时。
- **完成激励**：每完成一次计时或番茄钟累计一枚激励；首页无激励时只显示 1 个轮廓；有激励时只显示已获得的数量，最多显示 27 个，超过 27 个显示 `+N`。设置里可切换番茄 / 星星 / 泡泡 / 小鱼。
- **待办清单**：从工具页或悬浮球进入独立页，显示完整的自绘日历 + 时间面板、提醒提前量、点整条切换完成 / 点箭头编辑、月度日程圆点、键盘高度自适应；开启提醒会把待办写入手机系统日历，关闭小程序后由系统提醒，页面开着时也会震动弹窗。
- **声音与震动**：三种内置轻快铃声 + 导入并命名自定义铃声，可切换「仅震动 / 仅铃声 / 震动 + 铃声」；计时滴答声默认关闭，可在计时页或设置里打开。
- **主题**：蜂蜜奶霜（默认）/ 红黄汽水 / 蜜桃雪酪 / 晴空苏打 / 薄荷青瓷 / 曜石鎏金，另有自定义主色 / 底色 / 字色，命名保存后可长按删除，改色实时生效；底部 Dock 使用自定义 tabBar，背景、文字和图标都跟随主题。

所有数据都保存在本机 `wx.setStorageSync`，没有服务端，卸载小程序会清空记录。

## 快速开始

1. 用微信开发者工具「导入项目」，选择本目录。
2. AppID 使用 `project.config.json` 里的 `wx94c4673cd56b09ad`，或换成自己的小程序 AppID。
3. 点「编译」即可；计时页的时钟方向可在设置里切换「自适应 / 强制横屏 / 强制竖屏」，默认强制横屏；手机横屏不可用或桌面窄竖窗口会按实际窗口回退，真机与微信桌面「手机小程序」都要核对。
4. 发布前在微信公众平台配置：服务类目、隐私协议（相册保存海报）、订阅消息模板（待办提醒用）。

## 主题与样式

- 颜色只从 CSS 变量取：`var(--bg)`、`var(--primary)`、`var(--edge)`、`var(--shadow)` 等，不要写死色值。
- 改主题只改 `theme/palette.js`，然后执行：

```bash
node tools/gen-theme-wxss.js
```

脚本会重写 `app.wxss` 里 `THEME-TOKENS:START / END` 之间的 7 组 `.theme-*`，不要手改这一段。
- 自定义主题由 `app.buildCustomTheme()` 从主色 / 底色 / 字色推导出约 46 个变量，canvas 海报也走同一份配色。
- `pages/grade/` 的批改页不维护第二套主题：页面根节点读取 `app.getTheme()`，用 `.theme-*` + 自定义 `themeStyle` 继承当前配色；旧变量 `--accent / --amber / --pink / --blue / --edge-soft` 在 `pages/grade/base.wxss` 里映射到主程序 token。切换蜂蜜奶霜 / 晴空苏打 / 曜石鎏金等主题后，批改页和结果页雷达图一起变色。
- 批改七页沿用主程序同一套硬阴影卡片、胶囊按钮和入场节奏：首页总览大分数、答题选项回弹、结果页分数揭晓与印章、记录页大分数卡；从子页回到批改首页会重播入场。
- 批改页统一使用主程序的自定义顶栏（`navigationStyle: custom`），标题字号、字重、返回键和主程序 `.topbar` 同一套；不再混用原生导航标题字体。首页无记录时显示紧凑的 `0 次批改` 空态，不再用破折号占位。
- 预设卷的判断推理按公开题型分布拆为图形 / 定义 / 类比 / 逻辑；广东含科学推理，事业单位 D 含综合判断推理，没有统一细分的选调卷保持整块。子题型只拆题量与小节名，模块总分和卷面 100 分不动。
- 全高滚动页（打卡 / 待办 / 重要日子等）的底部净空放在滚动内容末尾的占位节点，不能写在 `scroll-view` 自身的 `padding-bottom` 上；否则 `height:100%` + `box-sizing:border-box` 会把可视区压短，在页面底部留下一条固定空白带。
- 逐题答题卡按内容高度收起，答题卡 / 交卷操作条固定贴底；桌面档不做整卡横推，改为轻位移淡入（手机档保留双卡推拉），优先保证宽窗口自动切题的帧率。

## 已知限制

- 待办提醒优先调用 `wx.addPhoneCalendar` 写入**手机系统日历**（需要 `scope.addPhoneCalendar` 权限，部分微信版本/设备可能不支持；失败时会退回小程序内弹窗）。微信订阅消息的离线推送仍需云函数或自建服务端，本项目暂未启用。
- 微信没有「创建桌面快捷方式」的开放 API，快捷入口只能用户在微信里手动「添加到桌面 / 我的小程序」。
- 历史记录只留最近 10 条，数据仅存本机。
