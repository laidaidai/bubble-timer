# 泡泡计时器

一个为备考刷题设计的原生微信小程序，小程序名「泡泡计时器」，首页叫「小鱼时钟」：把「番茄钟」和「模块化限时训练」合在一起，练完还能看到每道模块的用时、达标率和趋势。

奶黄 neo-brutalist 视觉：2rpx 描边、6rpx 硬阴影、圆角胶囊，配 5 套内置主题和可命名的自定义主题。

## 功能

- **三种计时模式**：正计时 / 倒计时 / 番茄钟（25 分钟专注 + 5 分钟休息，每 4 个番茄后 15 分钟长休息）。番茄钟直接叠加在模块训练上：专注段内某个模块练够目标分钟数就自动结算、切到下一个模块，全部完成才收尾。
- **模块化训练**：最多 8 个模块，拖动排序、单独设目标分钟；总时间 / 当前模块时间分开显示，翻页时钟、指针时钟等多种表盘可在计时页轻点背景切换，默认记住上次样式，计时页还带毫秒小字。
- **首页模板**：默认 6 模块（行测 150 分钟）、8 套真实考试预设模板（国考行测 / 省考行测 / 国考申论 / 事业单位公基 / 考研政治 / 考研英语 / 番茄专注 / 事业单位职测）、自定义模板；在设置里勾选预设会直接生成同名首页模板。
- **训练报告**：达标率、最耗时 / 最短时模块、逐模块明细，可保存打卡图、分享，也可一键「再练一次」直接进计时页。
- **数据与打卡**：今日目标完成度、本周累计、连续打卡、竖版打卡海报（canvas 导出）、弱项追踪（最近 12 次，忽略不足 1 分钟的训练）、多模块成绩趋势曲线。
- **待办清单**：自绘日历 + 时间面板、提醒提前量、点整条切换完成 / 点箭头编辑、月度日程圆点、键盘高度自适应；开启提醒会把待办写入手机系统日历，关闭小程序后由系统提醒，页面开着时也会震动弹窗。
- **声音与震动**：三种内置轻快铃声 + 导入并命名自定义铃声，可切换「仅震动 / 仅铃声 / 震动 + 铃声」。
- **主题**：蜂蜜奶霜 / 蜜桃雪酪 / 晴空苏打 / 薄荷青瓷 / 曜石鎏金，另有自定义主色 / 底色 / 字色，命名保存后可长按删除，改色实时生效。

所有数据都保存在本机 `wx.setStorageSync`，没有服务端，卸载小程序会清空记录。

## 快速开始

1. 用微信开发者工具「导入项目」，选择本目录。
2. AppID 使用 `project.config.json` 里的 `wx94c4673cd56b09ad`，或换成自己的小程序 AppID。
3. 点「编译」即可；计时页是横屏页面，真机预览效果最准。
4. 发布前在微信公众平台配置：服务类目、隐私协议（相册保存海报）、订阅消息模板（待办提醒用）。

## 目录结构

```
计时器/
├── app.js                  # 主题 / 铃声 / 预设模板 / 统计核心
├── app.json                # 6 个页面、自定义导航、按需注入
├── app.wxss                # 全局样式 + 主题 CSS 变量（自动生成区）
├── theme/palette.js        # 5 套主题唯一数据源
├── tools/gen-theme-wxss.js # 由 palette 生成 app.wxss 里的 .theme-*
├── utils/format.js         # 时间 / 日期格式化
├── utils/poster.js         # 打卡海报文案常量
└── pages/
    ├── index/              # 首页：模式切换、模板、模块编排、训练报告
    ├── timer/              # 横屏计时页：表盘、毫秒、模块进度
    ├── stats/              # 数据与打卡：总览、海报、弱项、趋势
    ├── history/            # 历史记录（最多 10 条）
    ├── todo/               # 待办清单 + 月度日程 + 提醒
    └── settings/           # 主题 / 铃声 / 预设模板 / 计时保护
```

## 主题与样式

- 颜色只从 CSS 变量取：`var(--bg)`、`var(--primary)`、`var(--edge)`、`var(--shadow)` 等，不要写死色值。
- 改主题只改 `theme/palette.js`，然后执行：

```bash
node tools/gen-theme-wxss.js
```

脚本会重写 `app.wxss` 里 `THEME-TOKENS:START / END` 之间的 5 组 `.theme-*`，不要手改这一段。
- 自定义主题由 `app.buildCustomTheme()` 从主色 / 底色 / 字色推导出约 46 个变量，canvas 海报也走同一份配色。

## 本地存储

| key | 内容 |
| --- | --- |
| `exam-timer-session` | 进行中的训练会话 |
| `exam-timer-records` | 训练记录，最新在前，最多 10 条 |
| `exam-timer-template` | `{ currentName, templates }` |
| `exam-timer-todos` | 待办清单 |
| `exam-timer-daily` | 每日训练秒数（统计 / 打卡用） |
| `exam-timer-settings` | 主题、铃声、震动、防误退等设置 |
| `exam-timer-theme` / `-clock-style` / `-mode` | 当前主题、表盘、计时模式 |

## 已知限制

- 待办提醒优先调用 `wx.addPhoneCalendar` 写入**手机系统日历**（需要 `scope.addPhoneCalendar` 权限，部分微信版本/设备可能不支持；失败时会退回小程序内弹窗）。微信订阅消息的离线推送仍需云函数或自建服务端，本项目暂未启用。
- 微信没有「创建桌面快捷方式」的开放 API，快捷入口只能用户在微信里手动「添加到桌面 / 我的小程序」。
- 历史记录只留最近 10 条，数据仅存本机。
